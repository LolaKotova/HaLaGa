# Einleitung
Die Klima‑Check‑Karten bieten eine kompakte und übersichtliche Darstellung von Klimaänderungen in Hamburg – sowohl für die Vergangenheit bis heute als auch für ein mögliches Zukunftszenario. Sie ermöglichen eine gezielte Analyse klimawandelbedingter Risiken. Je nach Jahreszeit können relevante, temperatur- oder niederschlagsbasierte Klimagrößen individuell zusammengestellt werden.

Diese Dokumentation beschreibt die Datengrundlagen und Methoden zur Analyse
historischer und zukünftiger Klimaänderungen.

Sie umfasst:

- Beobachtete Klimadaten

- Klimaprojektionen

- Methoden zur Bewertung der Robustheit

- Definition der verwendeten Klimagrößen und Indizes
