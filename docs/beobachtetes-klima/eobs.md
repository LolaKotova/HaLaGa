# E-OBS Datensatz

## Beschreibung
Die Auswertung zum aktuellen Klima basiert auf den Jahren 1994–2023 und wird mit dem Zeitraum 1950–1979 verglichen. Grundlage sind E‑OBS‑Daten – ein europaweiter Klimadatensatz, der auf Messungen von Wetterstationen basiert und flächendeckend für Analysen aufbereitet wird.​

## Verwendete Variablen
- Lufttemperaturen
- Niederschlag
- Weitere klimatische Variablen
